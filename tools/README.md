# 자동 작업 도구

- `post.sh <대상일> <종목> <장수> <저장소 경로>`: `대상일/종목/` 폴더의 이미지와 `caption_threads.txt`, `caption_instagram.txt`로 스레드 → 인스타 순서로 여러 장 게시물을 올린다. 토큰은 쓰지 않는다. 클라우드 환경의 네트워크 비밀 정보에 저장된 토큰을 프록시가 요청 헤더에 넣는다. 게시 전 중복 확인은 이 스크립트 밖에서 한다.
- `make_cards_example_2026-11-09.py <출력 폴더>`: 11월 9일 여자농구(우리은행 57-51 KB스타즈) 카드 4장을 RULES.md 3장 규칙대로 그린 예시. 매일 문구와 팀, 엠블럼만 바꿔서 쓴다. 스킬 파일은 클라우드 세션의 계정 스킬 폴더에서 읽는다.
- `make_standings_card.py <설정 json> <출력 png>`: 라운드가 끝난 날 결과 세트에 넣는 순위표 카드 1장을 그린다(RULES.md 3-10). 설정 json 형식은 파일 맨 위 설명에 있다.
- `make_award_card.py <설정 json> <출력 png>`: 라운드 MVP(농구는 MVP·MIP) 카드 1장을 그린다(RULES.md 3-12). 결과 세트 마지막 페이지에 넣는다. 설정 json 형식은 파일 맨 위 설명에 있다.
